# Optional conservative tool gate — disabled
This folder is outside plugin auto-discovery and the plugin manifest does not reference it. Nothing enables the example automatically. It is a deterministic protocol demonstration, not a sandbox, a semantic policy engine or evidence that review happened.

The preToolUse example allows exact documented tool names Read, Write and Task. It denies Shell, MCP, unknown tools, wrong events and malformed JSON; it writes only one JSON response to stdout and has no filesystem/network writes. Allowing Task or Write does not constrain all downstream behavior. Test commands will be blocked if this example is enabled; do not claim final tests passed. There is no stop hook, follow-up loop, regex shell allowlist or automatic reviewer certification.

To evaluate deliberately in a disposable local test project, review the script; copy/adapt `hooks.example.json` to that project's `.cursor/hooks.json` through your approved configuration process. Replace the placeholder with an absolute installed script path and the existing Python launcher. On Windows quote paths with spaces and use an existing `py -3` launcher if appropriate. Do not use this example as supplied. Version 1, preToolUse permission allow/deny and failClosed are documented. Hook working-directory/path quoting and Windows integration have not been runtime tested here. Verify JSON input/output and denied failure behavior in your installed Cursor before relying on it; keep it disabled if uncertain.

`failClosed: true` is intended to block on hook failure. `ask` is not used because Cursor documents it is not currently enforced for preToolUse. Organization policy/permissions and explicit review evidence remain necessary. Official source: https://cursor.com/docs/hooks.

Keep this example disabled for the native Plan/Build smoke test. Unknown tool names are denied and may include native plan or ask-questions tools. Hooks do not create plans, switch modes, invoke a Build callback or control UI. Do not broaden the allowlist based on guessed tool names.
